# Wix HP更新予約アプリ v0.2.0

Wixで保存した変更を指定日時以降に自動公開し、成功・失敗・結果不明・期限切れをメールで通知する、管理者専用のGoogle Apps Scriptアプリです。

- [アプリ一式をダウンロード](https://raw.githubusercontent.com/forestgym-tokyo/anauts-os-reserve/refs/heads/wix-publish-scheduler-downloads/downloads/wix-publish-scheduler/wix-publish-scheduler.zip)
- [導入済みアプリの更新手順](./UPGRADE.md)
- [スマホ画面](./app-mobile.png) / [PC画面](./app-desktop.png)（模擬環境の画面）

導入済みの場合は新規インストーラーを再実行せず、同じGoogleプロジェクト・同じURLを更新します。アップデーターは既存のコードをバックアップし、知らないコード変更や別プロジェクトを検出したら停止します。元のマニフェストと追加ファイルを保持し、メール送信スコープを追加します。

メール送信権限の再承認が必要です。登録済み予約の直前には更新しないでください。Google側の承認を済ませ、通知テストの受信を確認して使用します。Wix APIキーや予約の保存データをリセットする処理はありません。

メール送信に失敗してもHPを再公開しません。通知テストもHPを公開しません。指定時刻の秒単位の実行保証はなく、5分を超えて遅れた予約は未実行として記録します。公開時点の保存済み変更すべてが対象です。

検証：Nodeテスト36件、320/390/768/1280pxのブラウザーテスト成功。PowerShell 7/Linuxの模擬環境で正常更新・コード差分・別プロジェクト・破損ZIPの4ケースを確認しています。実サイトの公開とGoogle経由のメール受信は導入環境で確認が必要です。

実際の通知先は公開パッケージへ埋め込まず、利用者のGoogleアプリ内に設定します。このブランチは配布用であり、mainや既存予約システムを更新しません。
