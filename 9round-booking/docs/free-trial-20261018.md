## 受付条件

- 川上さん（`KAWAKAMI`）の有効なMPG勤務予定に45分枠が完全に収まる時間帯、および土曜日13:15を体験受付対象にします。MPG勤務予定のない時間を曜日の固定パターンで補完しません。
- 体験は1枠最大2名、無料です。1名または2名で申込みできます。
- デイリーワークアウトと体験は別枠・別定員です。平日は同じ開始時刻にデイリー4名・体験2名を受け付けられます。人数を合算しません。
- 「土曜日はデイリーワークアウトをなくす」の指定に従い、体験機能の有効化後は土曜日の新規デイリー受付を停止します。受付済み予約は削除・自動取消せず、会員の予約一覧とスタッフ画面に残します。
- 日付・期限は日本時間。予約・変更・取消は開始1時間前までです。

## 画面と操作

申込画面：`9round-booking/trial/index.html`。青と黒で、体験スケジュール、人数、氏名、同行者名、メール、電話、情報利用への同意を表示します。会員番号・カード情報は要求しません。

未入会者のメール確認後に予約します。確認コード送信だけでは枠を確保しません。申込IDによる再送防止と、既存予約と共通のScript Lockで体験定員を検査します。体験の予約・個人情報・セッションは追加の専用テーブルへ保存し、会員マスターへ書き込みません。

本人への確認メールと管理通知を別々に送ります。メール内の専用リンクで、6時間のログイン期限に関係なく対象の体験だけを確認・変更・取消できます。GETで状態は変更しません。変更・取消後に旧リンクを無効化します。メール送信に失敗しても予約を維持し、既存の管理者／マネージャー用の送信待ち再送を利用できます。

スタッフ画面の体験カードも青と黒です。本名・同行者・人数・メール・電話を確認でき、STAFF/MANAGER/ADMINが変更・取消できます。枠の設定・停止・削除・復元はADMINのみです。MPG勤務予定の変更後も成立済みの体験をスタッフ画面から隠しません。

## 本番反映前に必要な設定

この変更をGitHubへ保存するだけでは受付を開始しません。GASの既存デプロイの新バージョン公開と次の設定が必要です。既存の予約データ、会員マスター、公開URLは維持します。

| プロパティ | 設定 |
| --- | --- |
| `ROUND9_TRIAL_ENABLED` | 最後に`true`。未設定・`false`の間は既存の通常予約を維持 |
| `ROUND9_TRIAL_SHIFT_SPREADSHEET_ID` | `staff_shifts`を持つ既存A-nauts OSのスプレッドシートID。未設定時は既存スタッフ名簿のIDを使用 |
| `ROUND9_TRIAL_STAFF_CODE` | `KAWAKAMI`。既存MPG自動生成と同じコード |
| `ROUND9_TRIAL_URL` | 公開済み体験申込画面のHTTPS URL |

1. 新規`Trials.gs`、更新した`Booking.gs`・`SlotManagement.gs`・`Staff.html`を既存の独立9ROUND GASへ反映します。従来のGASファイルは削除しません。
2. エディターから`prepare9RoundTrialStorage_()`を1回実行します。`nr_trial_challenges`・`nr_trial_sessions`・`nr_trial_contacts`・`nr_trial_applications`の不足分だけを追加します。既存の初期化・本番準備は再実行しません。
3. 既存GASの実行アカウントが勤務予定の参照元を読み取れること、`staff_shifts`の列構成、実際の川上さんの勤務日時を確認します。参照元のデータには書き込みません。既存のMPG確定予約との時間重複は体験を受付停止にします。このPRではMPG予約側から体験予約を見る双方向連携は追加していません。
4. 公開ビルドに`trial/`を含めてGitHub Pagesへ反映します。`config.js`には確認済みの既存9ROUND API URLを設定します。
5. テスト用のメール・架空情報で実メール受信、勤務予定、予約・変更・取消を確認します。テスト申込を取り消してから、最後に`ROUND9_TRIAL_ENABLED=true`として受付を開始します。

```bash
node scripts/build-9round-gas-pages.mjs --staff-only
node --test tests/9round-booking.test.js tests/9round-trial.test.js
node tests/9round-trial.browser.cjs
```

コード・確認用デザインは開発ブランチでレビューします。`9ROUND trial review`のGitHub Actionsは架空のデータだけを使い、ブラウザー検証とPC・スマートフォン・スタッフ枠の画像を作成します。本番GAS・実会員・実メール・決済には接続しません。

Web入会・カード登録・初回／継続決済は、この体験受付と共通の顧客IDで後から接続する次段階です。本変更では料金の請求や決済代行との通信を行いません。
