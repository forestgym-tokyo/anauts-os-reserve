# 9ROUND 予約確認メールからの無期限セッション不要な変更・キャンセル（2026-10-18）

## 利用イメージ
The Forest Gymのパーソナル予約と同様に、会員宛の予約確認メールおよび管理通知メールにある「予約を変更する／予約をキャンセルする」をタップすると、対象予約の操作専用ページが開きます。6桁の確認コード再入力やスタッフログインは不要。キャンセルはページ上の「この予約をキャンセルする」をタップして確定し、日時変更は変更先の枠をタップして確定します。

## セキュリティと予約条件
- メールリンクに含む予約単位の64桁署名トークンで権限を検証（会員用と管理通知用で別のトークン）。
- **メールリンクの認可は6時間の通常ログインセッションと独立**。予約が有効で、開始1時間前より前なら、初回メール送信から6時間経過後も操作可能。
- メールリンクへのGETアクセスは**絶対に予約を書き換えない**。操作画面でボタンを押した時だけGASに認証付きPOSTする。メールソフトのリンクプレビューでキャンセルされない。
- トークンはURLフラグメントで配布し、操作画面は取り込み後にブラウザーのアドレスバーから除去する。トークンは他の会員データへのアクセスに使えない。
- 既存の開始1時間前締切、定員4名、変更先の空き枠判定、ブロック、受講済み制限、予約キャンセル／変更メール、管理操作履歴を維持。
- 予約がキャンセル・日時変更された後は**元予約のリンクでは新たな操作を行えない**。新しい変更後予約の通知には新しいリンクを発行する。
- 予約通知メール自体が操作権限を持つため、会員や管理者は第三者へリンクを転送しないこと。
