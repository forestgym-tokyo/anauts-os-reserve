# A-nauts OSへの9ROUND予約管理統合

ブランチ：`feature/9round-os-staff-integration`

このブランチは公開前の実装です。現在公開中の会員画面・独立スタッフ画面・GASバージョン4は変更していません。

## 画面とログイン

A-nauts OSの上部メニューに「9ROUND予約」を追加します。既存ログインのFirebaseトークンを使い、9ROUND用の再ログインは不要です。9ROUND担当のスタッフ（SOGA所属または`can_9round`）、マネージャー、管理者に表示します。SOGAスタッフ向けのナビゲーション制限も、このタブを許可します。

タブを開いたときに独立9ROUND APIから予約状況を読み込みます。通信前に既存の認証更新処理を呼び、更新後のトークンを渡します。既存A-nauts GASのルーターやシフト・入会・退会処理は変更しません。

独立スタッフ画面とA-nauts内の画面で、予約一覧、変更・キャンセル、QR受講登録、枠管理のコンポーネントを共用します。ログアウト・利用者切替時は会員情報を消し、途中の通信応答も反映しません。サーバー側で拒否された場合も予約情報を消します。

## 権限

| 操作 | スタッフ | マネージャー | 管理者 |
| --- | --- | --- | --- |
| 予約状況・本名・ファイターネーム・受講状態の閲覧 | 可 | 可 | 可 |
| 予約の変更・キャンセル | 可 | 可 | 可 |
| 会員QRの受講登録（既存機能） | 可 | 可 | 可 |
| 体験枠の設置・編集 | 不可 | 不可 | 可 |
| デイリー枠のブロック・解除 | 不可 | 不可 | 可 |
| 枠の削除・復元 | 不可 | 不可 | 可 |
| 未送信メールの再送（既存機能） | 不可 | 可 | 可 |

権限は画面の表示だけでなく、独立GASでFirebaseと有効なスタッフ名簿を確認して判定します。リクエストの`permission`等で権限を変更できません。通常スタッフの他店舗制限、会員本人確認、会員ステータス`ok`の条件は維持します。

予約変更・キャンセルの締切は開始1時間前までです。変更先の空き・受付停止・定員・受講状態を検査し、元の予約を保護します。操作したスタッフコードを既存の管理操作記録に残し、会員・管理者への通知も共用します。

## 削除と復元

デイリー枠と体験枠を削除できます。予約が入っている枠は削除を拒否します。成立した予約を自動で取り消しません。削除は行を消さず、既存の`nr_blocks`または`nr_trials`に`DELETED`を記録します。スプレッドシートの列構成や既存データの初期化は不要です。

削除済みの枠は会員・スタッフ・マネージャーの一覧から外し、直接指定による予約・変更も拒否します。管理者の一覧には「削除済み」と「枠を復元」を表示します。復元後は受付停止となり、管理者が明示的に解除・編集して受付を再開します。一日分のブロック解除でも、削除済み枠は復活しません。

## 確認方法

```bash
node scripts/build-9round-gas-pages.mjs
node --test tests/9round-booking.test.js tests/admin-auth-refresh.test.js tests/direct-shift-permission.test.js
node tests/9round-booking.browser.cjs
```

ブラウザーテストでは架空の会員・スタッフとローカルのGASテスト実装だけを使います。既存の会員予約・QR・メール操作に加え、A-nautsの実際のSOGA権限処理とCSSを読み込み、共有ログイン、スタッフの予約変更・取消、マネージャーに枠管理を表示しないこと、管理者の枠削除・復元、権限偽装の拒否、ログアウト後の遅延応答、スマートフォン幅を確認します。

## 本番反映時

今回の作業ではブランチへの保存までを行います。公開するときは、独立GASへ`SlotManagement.gs`を含む更新済みサーバーソースと生成済み`Staff.html`を配置し、同じデプロイを新バージョンへ更新します。A-nauts側はこのブランチの統合スクリプト・共通スタッフ部品・ナビゲーション・キャッシュ更新を反映します。

ソースの`9round-booking/config.js`はレビュー用に未接続です。公開中mainの会員用設定を空の設定で上書きせず、確認済み独立GAS URLを使った公開ビルドを維持してください。A-nautsでは既存ログインを利用するため、9ROUND側でFirebaseのパスワードを再入力させる設定は不要です。スタッフ通知のリンクをA-nautsへ変更する場合は、確認済み管理画面URLに`view=nineRoundBooking`を付け、`ROUND9_BOOKING_STAFF_URL`だけを更新します。会員用URLやコードコピー用URLを変更する必要はありません。

復旧時は統合スクリプトの読み込みを戻し、従来の独立スタッフ画面を利用できます。GASバージョン4も履歴に保持します。予約用スプレッドシートの削除・再作成や初期化は行いません。
